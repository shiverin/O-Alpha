Motivation

Retail investors need quant-grade automation without deep infrastructure work. O(Alpha) turns strategy research into accessible, systematic execution.

The problem

Research, execution and account state can drift apart when validation, background workers and persistence are loosely connected.

Our solution

A gated research-to-execution pipeline with explicit lifecycle states, normalized data and a reconstructable audit trail.

User Stories
Beginner
Choose a strategy that matches a saved risk profile.
Researcher
Inspect repeatable validation evidence before launch.
Portfolio
Start, observe and stop one strategy agent safely.
Maintainer
Trace each run from target weights to persisted fills.
Engineered Features VERIFIABLE

Onboarding & Catalog

Risk profile, compatible strategy and accepted backtest stay aligned.

Validation Gate

No-lookahead, walk-forward, DSR/PBO and cost stress; missing evidence fails closed.

Execution Router

Deterministic order keys; reductions are processed before buys.

Atomic Ledger

Orders, fills, cash and positions update inside DB transactions.

Lifecycle Resume

Run state, heartbeat and runtime HMM state survive restarts.

Observable Dashboard

Snapshots, positions, fills and alerts come from persisted state.
